# Pemrograman_MarcelliusElloErnesto_Mariposite

Repository Pemrograman_MarcelliusElloErnesto_Mariposite berisi tugas pemrograman C++ yang terdiri dari dua problem beserta dokumentasi algoritmanya.

Problem 1 – The Last Astronaut
Berisi program C++ yang mensimulasikan proses eliminasi astronot berdasarkan jumlah astronot (N) dan nilai eliminasi awal (K). Program menampilkan urutan astronot yang dieliminasi hingga menentukan astronot terakhir yang bertahan. Dokumentasi pada PDF juga berisi pseudocode Problem 1 yang menjelaskan langkah-langkah algoritma dari program tersebut.
Problem 2 – Alien-in-the-Middle
Berisi program C++ untuk melakukan enkripsi terhadap pesan menggunakan aturan perubahan nilai huruf kapital berdasarkan huruf sebelumnya. Selain kode program, PDF juga menyertakan flowchart Problem 2 yang menggambarkan alur proses program mulai dari input pesan, pengecekan karakter, proses enkripsi, hingga menampilkan hasil enkripsi.

Dengan demikian, repository ini tidak hanya berisi source code (.cpp), tetapi juga dokumentasi algoritma berupa pseudocode dan flowchart dalam file PDF, sehingga proses penyelesaian kedua problem dapat dipahami baik dari kode maupun representasi algoritmanya.
